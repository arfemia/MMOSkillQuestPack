# Patch notes - MMO Skill Quest Pack

Per-version public release notes (newest first). Same paradigm as the main mod repo: YAML frontmatter (`version`/`type: patch-note`/`status`), user-facing voice, no em-dashes. `CURSEFORGE.md` is the public listing; keep its Versions table in sync.

- [[1.1.0]] - held (ships with plugin 1.6.1 and ZiggfreedCommon 2.1.0): the Scarak Brood Queen, a world boss a server owner places once under the desert (three phases, shared credit and share-scaled loot, a boss bar, a map marker, a leaderboard, her own notices), the Brood Below quest capping the desert campaign (held with it), Ashkar's lines about her, and the Wren bread-offer audit fix.
- [[1.0.0]] - released (ships with plugin 1.6.0): first release, the Emerald Wilds questline, the Kweebec Nightmares arc, the Night Owl ladder and the Nightwarden set; the Howling Sands questline is authored but held back for a later release.
